- **App ID:** airtable
- **Project:** Swell integration app (generic, no extensions) that syncs orders (+ line items), customers, products (+ variants), subscriptions, coupons and categories to Airtable. `functions/record-events.ts` upserts records live (merged on the `Swell ID` column; child rows linked to parent rows). Optional write-back: columns with `writeTo` in `tables.ts` are polled every minute by `functions/pull-edits.ts` (cron, logic in `functions/lib/pull.ts`, state per table in `apps/airtable/pulls`) and written to Swell when they differ. Sync jobs in `apps/airtable/syncs` (`test`, `setup`, `backfill`) run step by step in `functions/sync-run.ts`. Column mappings live in `functions/lib/tables.ts`, the Airtable client and schema logic in `functions/lib/airtable.ts`. Retryable job errors set `waiting` + `date_retry`; `functions/sync-retry.ts` (model schedule) resumes them.
- **Rules:** credentials and options only in `settings/airtable.json`. Every function has vitest unit tests. Keep README.md current. Don't run `swell app version`/`release` or commit without asking.
- **Tools:** Swell skills, Swell CLI. In Git Bash set `MSYS_NO_PATHCONV=1` before `swell api` calls with `/` paths.
